ILLUSION OF GAIA COMPANION
==========================

Found a problem? Please report it (see WHEN YOU REPORT A PROBLEM below):
https://github.com/rages4calm/babel-recomp-companion/issues

WHAT YOU NEED
- Windows 10 or 11, 64-bit.
- Your own Illusion of Gaia (USA) ROM (.sfc or .smc). No game data is
  included in this download.
- The .NET 8 Desktop Runtime for the launcher:
  https://dotnet.microsoft.com/download/dotnet/8.0

HOW TO START
1. Unzip the whole folder somewhere you can write to (not Program Files).
2. Run illusion-of-gaia.Companion.exe.
3. On the Game page, choose your ROM, press Apply, then Play.

IF WINDOWS SAYS "Windows protected your PC"
The programs are not code-signed (signing costs money every year), so
Windows warns about any new download like this. Click "More info", then
"Run anyway". Only download the game from the GitHub Releases page.
If your antivirus removes a file, restore it and add the folder as an
exception. If the launcher does not open at all, install the .NET 8
Desktop Runtime (link above).

WHAT IS ON BY DEFAULT
- Wide view: more of each area around the original picture.
- The GaiaLabs Retranslation script.
- The walkable world map, with the enhanced view.
Each can be turned off: Wide view is the Picture choice on the launcher's
Display page, and Enhanced world map is under Cheats and Mods. See i18n/GAIALABS-NOTICE.md for the other two.

MUSIC
The game plays its original SNES music. To use an MSU-1 orchestral pack,
open the launcher's Soundtrack page and import the pack's ZIP or folder;
that turns it on. "Use original audio" on the same page turns it off.

UPDATING
Click Update in the launcher. It downloads the newest release, keeps your
saves, settings, keybinds, soundtrack and achievements, and moves your
shortcut to the new folder.

IN THE GAME
- Esc (or Left Trigger + Right Stick click): settings
  Achievements are in the settings.
- Start: the area map, wherever the area has one
- Shift+F1 (or Left Trigger + R): save state
- F1 (or Left Trigger + L): load state. It asks first.
- F11 (or Left Trigger + Start): all save states
- Alt+Enter: fullscreen

WHEN YOU REPORT A PROBLEM
1. Before playing, make a folder named diagnostics next to
   babel-recomp.exe and put an empty file named on.txt in it.
2. When you see something wrong, press PrtSc (the screenshot key). That
   saves a picture and marks the moment in the diagnostics log.
3. Open an issue (link at the top), say where you were and what you were
   doing, your Picture setting (Wide / Classic 16:9 / Original 4:3) and
   controller, and attach the screenshot and the files from diagnostics.
